Send a test letter to every unit (shown as a transient — the clock comes back by itself), then type what each drum is actually showing. Apply All writes the corrected offset to each unit and re-homes it.

Advanced: raw jog & offset

Provisioning

Each unit can store its I2C address in EEPROM; the DIP switches become a fallback. Burn all locks in the current addresses (do this before DIP switches are ever removed). Changing an address away from its DIP setting breaks that unit's over-I2C reflash until the address is cleared again.

Display width auto

Dummy mode for benches without (all of) the units: pin the display width instead of deriving it from the I2C probe. 0 = auto (probe-derived). Real units keep working; missing ones simply show as unreachable.
