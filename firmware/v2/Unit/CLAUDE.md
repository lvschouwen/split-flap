# v2 Unit (Arduino Nano)

Loaded when working in this tree; root CLAUDE.md holds build commands, workflow and Hard rules.

`Unit.ino` (config, globals, setup/loop) + siblings `UnitI2CProtocol.ino` (TWI ISRs + addressing) and `UnitMotion.ino` (stepper + hall calibration) — a one-TU concat model, main sketch placed first. I2C address: four DIP pins + `I2C_ADDRESS_BASE` (DIP 0000 → 0x01; 0x00 reserved for general call), or EEPROM-provisioned address with DIP fallback — twiboot still listens on the DIP-derived address, so over-I2C reflash requires EEPROM == DIP. 28BYJ-48 via ULN2003, KY-003 hall homing, per-unit EEPROM step offset clamped to ±`SFP_OFFSET_LIMIT_STEPS` on both protocol sides. Revolution odometer (#231): every drum move funnels through `stepCounted()`; ring policy pure in `UnitOdometer.h` (`pio test -e native` runs here too). EEPROM layout + block integrity pure in `UnitEeprom.h` (#406, day-0 — every block checksummed and every failure degrades to a safe default; the ring sits last so new scalars never move it, landing at `EE_RESERVED_NEXT_FREE`). The layout is **block-addressed, not version-addressed**: adding a field does NOT bump `UNIT_EE_LAYOUT_VERSION` (that means erase-everything and costs 21 hand-measured offsets), and a region earns its own version byte only when its repair is strictly cheaper than that full erase — `EE_RING_INIT_VERSION` (#417) is the one that qualifies. Lifetime health (what the unit remembers about its own decline across power cycles) reads back via `GET_LIFETIME` → `UnitLifetime.h`. **Feature gates (EEPROM byte 11, `UNIT_GATE_*`):** the two motion changes ship OFF so one fleet reflash can be proven incrementally; `SET_GATES` (0x99) / `POST /unit/gates` flips them over the wire on both row masters, verified by a `GET_LIFETIME` read-back, and the unit refuses bits it has no code for. Idle hall consistency check (#268, behind `UNIT_GATE_IDLE_HALL_CHECK`): pure `UnitIdleHall.h` predicts the hall reading from the parked position and arms the existing #263 re-home on a debounced contradiction — coverage is partial by physics (see the header). Calibration/provisioning driven from the master's web UI. Probe quirk: twiboot pinned alive by `isUnitInBootloader()` probe — the 1500 ms pre-probe delay is load-bearing.
