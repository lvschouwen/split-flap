# v2 Rescue (factory-slot break-glass image)

Loaded when working in this tree. Never `pio run -t upload` this project (root Hard rules) — install via Master's `POST /firmware/rescue` or `esptool write-flash 0x830000`.

- **Factory slot (#193):** 2 MB `factory` app partition; bootloader factory reset (GPIO 4 low 5 s through reset) erases **otadata only** — never nvs (WiFi credentials must survive).
- **Rescue app (#195):** standalone project that depends on nothing in the Master tree except the partition CSV — `Rescue*.h` pure headers are trimmed, natively tested copies. Pure headers under `firmware/v2/shared/` are fine (compiled into this image at its own build; `LanOrigin.h` is the CSRF/LAN-origin rule of all three HTTP boards, #531; `NvsContract.h` the NVS namespace + keys this image reads from what Master wrote, #537; `OtaUploadGate.h` the upload gate, completion verdict and stall rule, #532 — `rescueWebTick()` releases an upload session silent for 30 s). Boot: NVS read-only → 30 s STA join else `<name>-rescue` AP (captive) → slot inventory + upload-to-app0 (same `?md5=` contract) + `/rescue/exit`. Enter via GPIO 4 or `POST /firmware/rescue-boot` (409 while an install is in flight or the factory image is invalid). Master installs it via raw `esp_partition` writes (`FactorySlot.cpp` — flash sector 0 held back until the MD5 verdict, pure `FactoryChunkPlan.h`).
- **Release fetch (#583):** joined to WiFi, `POST /rescue/release/look|install?channel=stable|test` fetches the master image of a signed release into the slot an upload writes — master image only, no clock, the person decides. `../release/` is compiled into this image as it is into Master (site, key, order of verify → write → activate); `RescueRelease.h` is what rescue adds (pure), `RescueReleaseJob.cpp` the glue. The job is admitted on the web server's task and runs in `loop()` (16 KB stack for the TLS handshake); it and an upload refuse each other (one `Update` session), and `/rescue/exit` waits for both. Needs `CONFIG_MBEDTLS_EXTERNAL_MEM_ALLOC=y`, as Master. A new rescue image is tried first as an upload to a running master's `POST /firmware/master` (it runs from the other app slot with the rollback behind it) before it goes into the factory slot.

Custom bootloader + Master-side install path: `firmware/v2/Master/CLAUDE.md`.
