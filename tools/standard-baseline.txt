# Code standard baseline (#653); limits and rules in docs/CODING_STANDARDS.md 1.5.
# Format: metric<TAB>key<TAB>value. Metrics: nloc (key = file), len ccn nest params (key = file:function, a second
# function of the same name in a file is file:function#2), moved (a deliberate rename record).
#
# The entries are existing offenders past the fail line, held at their current value, and may only SHRINK. The gate
# fails on an entry that is new or higher than in the merge-base copy of this file, and on an entry whose offender
# was fixed or lowered (remove or lower it).
#   - Fixed or lowered an offender? `python3 -I scripts/check_standard.py --shrink` drops or lowers entries (never adds).
#   - Moved a file or renamed a function? `python3 -I scripts/check_standard.py --rename OLD NEW` (a path, or
#     path:function) moves the entries keeping their values and leaves `moved` records the gate accepts.
